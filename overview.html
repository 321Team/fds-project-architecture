FDS 서비스 흐름과 설계 범위

FDS(이상금융거래탐지시스템)는 거래 정보에서 위험 징후를 판정하고 결과를 기록하는 서비스입니다. 이 문서는 서비스 처리, 배포 절차, 클라우드 연계의 책임 경계를 처음 읽는 분도 이해할 수 있도록 설명합니다.

설계와 검증 완료를 구분합니다.
2026-10-16 대조 기준입니다. 정본 v3.1.21과 후속 변경결정에서 채택한 방향을 설명하며, 모든 구성의 실제 동작·최종 인수를 뜻하지 않습니다.

1. 거래를 처리하는 흐름

사용자 요청

거래 정보를 전달합니다.

거래 API

입력과 기존 이력을 확인하고 판정을 요청합니다.

↔

탐지 엔진

규칙으로 위험 징후를 판정해 결과를 반환합니다.

거래 API가 데이터베이스에서 기존 이력을 읽고 거래·판정 결과를 저장합니다. 탐지 엔진은 데이터베이스에 직접 접근하지 않는 구조입니다. 교육 프로젝트의 규칙 기반 탐지이며, 금융 거래의 실제 차단이나 상용 탐지 정확도를 입증한 자료는 아닙니다.

2. 변경을 검사하고 배포하는 흐름

테스트·보안 검사

프로그램 실행을 확인하고 실패한 변경의 후속 진행을 차단합니다.

→

프로그램 저장소

승인한 컨테이너 이미지와 검사 결과·내용 식별값을 연결합니다.

→

서버 배포

배포 대상, 실행 상태와 복구 결과를 별도로 확인합니다.

컨테이너 이미지는 프로그램과 실행에 필요한 파일을 묶은 배포 단위입니다. 저장소 전송 성공은 서버 배포 성공과 다르며, 서버 실행도 최종 인수와 구분합니다. 상세 시험의 조건·결과는 해당 실행 기록을 기준으로 판단합니다.

3. 클라우드 연계에서 채택한 방향

설계 방향

  • AWS EC2 기반 Libreswan 중계와 IPsec 암호화 통신으로 교육장 환경을 연결합니다.
  • AWS 관리형 OpenShift인 ROSA HCP를 사용합니다. 단일 가용영역 범위는 애플리케이션 실행 서버(Worker)에 해당합니다.
  • Harbor가 주 저장소이며 클라우드는 이미지를 내려받습니다. ECR은 수동 대체 경로로 채택했고 자동 복제는 범위에 포함하지 않습니다.
  • VPN 경로는 승인된 시험 시간에 사용하며 상시 운영을 전제로 하지 않습니다.

별도 검증·판단할 항목

  • 암호화 연결과 데이터베이스 접근의 실제 동작
  • 이미지 내려받기와 수동 대체 경로의 실제 동작
  • 배포 작업의 정상·실패 경로 및 복구 결과
  • 생성된 자원과 설계의 일치 여부, 최종 인수

검증이 필요한 방향을 채택했다는 것과 검증을 끝냈다는 것은 다릅니다.

4. 상세 도면을 읽는 기준

  • 1차 도면은 v3.1.19 당시의 기록입니다. 과거의 진행 상태와 연결 후보가 포함되어 있으며 현재 운영 현황표로 사용하지 않습니다.
  • 2차 도면은 클라우드 연계 설계입니다. 채택한 방향과 실제 환경 검증 대기 항목을 함께 읽습니다.
