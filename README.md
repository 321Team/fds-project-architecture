# FDS 아키텍처 문서

팀 프로젝트의 서비스 흐름과 설계 범위를 설명하는 정적 HTML 문서입니다. 시작 페이지는 `index.html`, 읽기 안내는 `overview.html`입니다. 설계 채택과 실제 환경 검증·인수 상태를 구분합니다.

## 도면 갱신 시 보존할 내용

- 도면을 다시 내보낼 때 각 페이지의 `revision-note`와 `context.css` 연결을 보존합니다. 현재 저장소에는 도면 생성 원본이나 자동 재생성 파이프라인이 포함되어 있지 않습니다.
- 2차 논리 도면의 가이드 6개, 기존 노드 ID와 namespace·네트워크 정책 설명을 보존합니다. 사양 오류에 따른 연결 수정은 근거와 예외를 기록합니다. 상태 문구를 바꿀 때 화면 텍스트, title, aria/data 속성, 가이드 설명을 함께 대조합니다.
- 1차 물리 도면은 커밋으로 고정된 원본을 불러와 보완합니다. 원본을 바꿀 때 `patch()`의 마커 검사와 안내 삽입을 확인합니다. 필수 마커가 없으면 오류를 표시해야 합니다.
- 브라우저에서 문서 목록·개요·도면 안내와 가이드 전환을 확인합니다. 정적 검사나 화면 확인을 서버 Runtime·최종 인수로 기록하지 않습니다.

## 현행 정본과 이력

- 현행 공개 설명: docs-v3.1.22 (2026-10-19). 근거·검증 경계는 `canonical-status.html`에 기록합니다.
- 1차 현행: `phase1_logical_current.html`, `phase1_physical_current.html`. 정본의 구성 기록·후속 관측을 구분해 설명합니다.
- 이전 1차 `logical_architecture.html`, `physical_architecture.html`은 변경 없이 이력으로 보존합니다.
- 2차 기존 인터랙티브 도면은 기존 노드 ID·가이드 ID와 주요 형상을 보존하고 확정 설계 설명을 동기화합니다. 이미지 pull의 실제 주체를 표현하기 위해 Worker 노드 1개를 추가하고 해당 연결 1개만 앱에서 Worker로 정정했습니다. 이는 확정 사양의 node pull / Pod 정책 구분을 반영한 변경입니다.
- 공유 폴더의 9월 발표/영상은 현행 검증 자료로 다시 이름 붙이지 않습니다. 정본 발행·조건부 종결은 새 Runtime PASS와 다릅니다.
- 외부 공개본에 공유 경로·계정번호·자격정보·개인 연락처·비공개 원본 로그를 복제하지 않습니다.
